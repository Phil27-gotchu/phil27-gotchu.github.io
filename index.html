03 // projects

b&s terminal: nasdaq + bse

2026

a bloomberg-style market and options terminal for nasdaq and bse. live market monitors, candle charts, implied-vol smiles, garch(1,1) vol forecasts with no look-ahead, a monte carlo pricer, and a delta-hedge backtest on real crisis windows like 2008, covid and svb.

  • python
  • fastapi
  • numpy
  • plotly
  • quant finance

jaundice screening probe

2026

an esp8266 probe with a colour sensor, oled and sd card that takes a 5-second skin reflectance reading and streams it to a live dashboard. it's in a hospital right now, collecting a dataset from newborns. a screening aid, not a diagnosis.

  • esp8266
  • arduino c++
  • node.js
  • iot
  • healthcare

github ↗ live ↗

smart parking allocation

2026

indian number plate recognition for a parking allocation system. a webcam captures the vehicle, yolov8 finds the plate, and a fine-tuned 36-class cnn reads each character into the standard hsrp format, with position-based correction of common ocr swaps. handles single- and two-line plates, plus night-time enhancement.

  • python
  • yolov8
  • pytorch
  • opencv
  • computer vision
